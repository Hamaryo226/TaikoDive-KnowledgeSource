# 01b 起動・曲決定・段位・ロード・結果の遷移

## 起動と曲決定

タイトル表示設定が有効ならデモから開始し、無効なら選曲へ直接入る。タイトルのモード選択で段位道場を選べば段位選択、それ以外は選曲へ進む。F12は入力コード88として扱い、検索画面が開いているときは共通処理を行わない。起動時の素材不足については13章を参照。

通常曲の難易度を決めると選曲画面内でロード導入を描き、演奏用テクスチャを先行準備する。カウンタ1920から幕、2280以降は待機画面、曲名・副題・ヒントを表示する。2528を超えた曲名表示を少なくとも2フレーム行い、かつ演奏用テクスチャが準備できた時点で、試聴を即時停止・解放しジャンルボイスを停止、選択譜面を読み込む。続いてロード表示を開始し、検索状態を次回用にリセットして演奏シーンに切り替える。AIでは専用導入を使い、カウンタ3528で同じ遷移処理を試み、テクスチャ未準備なら待機する。譜面の事前解析が済んでいる場合は本読み込みに引き継ぐ。

## 段位選択

初回・リセット時の選択段位は先頭、確認ボタンは位置2である。再読込時は選択譜面を可能な限り維持する。末尾の戻る用要素を除いて段位を循環する。登場演出では暗転、文字の順次出現、左右への画面展開の後に札が順に現れ、入力は登場カウンタが `5390 + 要素数×40` 以上かつ設定画面が閉じている間に限る。キャラクターは左上のオフセットから所定位置へ入る。

段位道場では段位の札と、構成曲の曲名・難易度・星数、魂ゲージ基準、各課題の種別・基準値・以上／未満を表示する。課題には全曲共通と曲別がある。左右で札を循環し、札交換音と切替演出を出す。決定すると挑戦確認が開き、決定音と注意音を鳴らす。確認アニメーションのカウンタが770未満では操作を受け付けない。確認中の左右はボタン位置0〜2の範囲で移動し、循環しない。位置2の決定は確認を閉じ、位置1の決定は挑戦を確定する。位置0の決定は何もしない。Escapeは段位BGMと注意音を止めてタイトルのモード選択へ戻る。ロード演出開始後は入力を受け付けない。

挑戦確定で決定音と段位決定ボイスを鳴らし、選択画面内のロード演出を開始する。カウンタ3000から暗転、3740を超えると段位ロード背景と札を表示する。7250到達後も演奏用テクスチャが未準備なら待機し、準備できたらBGMを止め、コース3を指定して選択段位の譜面を読み、ロード画面の開始と検索状態のリセットを行い演奏シーンへ移る。段位が消失した場合は選択処理を継続しない。

## 演奏シーン上のロード表示

ロード表示は独立したシーンではなく、演奏画面の上に重ねて描く。譜面読み込み後に開幕カウンタ0〜2880を開始し、毎フレーム進め、終端で停止する。終端到達そのものでは別シーンへ遷移しない。演奏画面はその下で既に描画される。

- 通常：曲名・副題・ヒントを表示し、1776からフラッシュ等を消し、1920から幕を左右に開く。叩打音は1900以上で許可する。
- AI：480までは黒、以後専用背景と中央から広がるパネルを表示し、曲名・副題・ヒントを載せる。2578から暗転、2630以降に演奏画面へフェードインする。叩打音は開幕カウンタ終端2880まで抑制する。
- 段位：冒頭は段位ロード背景と札を保持し、336から暗転、816〜960の暗転中に最初の曲のジャンルを設定しゲージ・ゴーゴー・連打・風船状態を初期化、段位パネルと幕音を開始する。960から1440にかけて明転する。

## 演奏終了と結果

演奏終了後の暗転カウンタが3000に達すると結果シーンに入り、通常／AIは通常結果、段位譜面は段位結果の処理を使う。結果画面への移行時に成績の保存・選曲表示の更新を行うが、モードやプレイ条件による保存可否を区別する。

### 通常・AI

曲名・副題、難易度、オプション、プレイヤー名、魂ゲージ、スコア、良・可・不可、連打数、最大コンボ、スコアランク、王冠を表示する。2人／ゴーストでは対応する側にも成績を描く。結果音は導入音の後にループへ移る。数値は拡縮して現れ、ゲージは実際の値まで伸びる。クリア基準到達で文字やキャラクターの表示が変わり、100%では魂の光を重ねる。ランクと王冠は出現後に光る。背景・雲・山・キャラクター・吹き出しを重ねる。

AI結果は相手キャラと3区間または5区間の勝敗パネルを表示する。縁入力で各区間の内訳に切り替え、区間名・勝敗・王冠・スコア・良可不可・連打を示す。音符のない区間には王冠を出さない。通常1人演奏でも詳細結果設定が有効なら区間内訳を表示するが、AI相手・区間勝敗は出さない。

数値演出カウンタ8230以降、面入力で決定音とフェードアウトを開始する。ループ音量と画面を段階的に落とし、フェード終了時に選曲関連をリセットして選曲へ戻る。AIの縁入力は内訳表示切替に使う。

### 段位

段位結果は魂ゲージと課題の達成値を順に現し、全曲共通課題は大きなゲージ、曲別課題は各曲の小ゲージで表示する。達成度に応じた色・虹色演出、数値のポップ、最後の段位判定の拡大と光を重ねる。段位結果の音を再生し、段位判定の演出終了後に面または縁の押下・押し続けを受け付ける。入力後は音量を下げつつ黒へフェードし、カウンタ終端で結果カウンタをリセットして段位選択へ戻る。
