# 01c｜コイン受付・デモ紹介・難易度オプションの詳細

この補足は 01 の調査時点の未確定記述に優先する。G/A は 00 の固定版を示す。キーコードと物理キー表示を区別する。

## SCENE-A01 コインとタイトル

| 入力（DxLib コード） | 共通処理 | デモ中の結果 |
|---|---|---|
| PageUp (201) | 通常コインを +1、投入 SE | タイトルへの退出開始 |
| Home (199) | 総数とサービス数を各 +1、サービス SE | タイトルへの退出開始 |
| PageDown (209) | 総数を 0 底で −1、サービス数を総数以下に詰める。払い出し SE は鳴らさない | **退出条件ではない** |
| 上段数字 1〜9 (2〜10) | 最初に当たったスロットを選択 | カードを予約して退出開始。コインなしでもカード読込から始められる |
| 1P/2P の面（設定された左右いずれか、フリープレイ時） | 打った感触のドン SE | タイトルへ進む。その打撃でタイトルの参加処理を同時には実行しない |
| Esc (1) | DxLib 終了 | 同じ |

共通処理はデモとタイトルで画面処理より先に 201→199→209 の順に全判定し、加算が一度でもあれば退出フラグを返す。通常分から減ったのと同じようにサービス数は最後まで残り、サービスが 1 以上なら赤表示。同フレームにカードを押した場合も、退出フラグとは別にカードを保持。以下タイトル受付では `FreePlay` はコイン決済を不要にするが、画面を進む打撃は必要。既存の E2E スクリプトに PageDown を coin とする記述があるが、実装の優先は上表。根拠：`G/src/Common/Program.cs::tクレジット入力を処理する`、`G/src/Scenes/Demo/Demo.cs::tDraw`。

**受付スロット**は P1/P2 二枠、空を −1 とする。同ユーザーを二枠に入れない。1人目はタイトル待機から、2人目は最初のモード選択が開始されていて、モード決定前、別枠カード読込中でないとき受け付ける。フェード中のカードは 1 件だけ保留し 3D の先読みを開始、明転後に読込。カードを受理した順ではなく P1→P2 で毎フレーム未精算枠へ 1 枚ずつ**予約**する。残数は総数から未消費の予約数を差し引いた値で判定。予約しただけでは表示枚数を減らさない。1人目は太鼓の側の確定、2人目はカード読込完了で予約 1 枚を消費し、取り消し時に実消費済みの場合は総数だけ戻す。

カード読込カウンター 1 段階は 1100µs、値 2260 以上を完了とする。1P 太鼓選択は中央「つかわない」が初期、D/K（コード32/37）で 0〜2 の範囲を動かす。既定のこの画面の決定は F または J（33/36）。index 0「みぎ」は内部 `nPlayer=0`、index 2「ひだり」は `nPlayer=1`。中央は取消 SE、枠解放、太鼓とカードのカウンターを初期化し、同フレームに「太鼓を選んでね」を再発火しない。決定した太鼓パネルは選択カウンター 660〜910 で線形に消える。910 を超え初回だけモード音声・バー・左上太鼓導入を始める。入場側の SE/声のタイミング：コイン無なら挿入催促、有/フリーなら太鼓で開始、カードの読込が進めば双方停止。読込と精算、両方成立するまで該当エントリー声を遅延。位置による 1P/2P 音声は「`nPlayer==1` XOR 2人目」で右辺の声を選ぶ。1P でフリー打を受けるのは両方の割当、2人目でフリー打を受けるのは `P2Keys`。この場合まずドン SE と 730ms のバー閃光を開始し、終了後カード読込を模す。2P の既定アカウントが同じなら次の番号へ循環。

**モード**は左 AI／中央 通常／右 段位、初期は中央。初回のバー開きは 596ms、左右移動は 526ms。D/K は左右に制限、アニメーション完了・2P 読込終了まで入力を待つ。F/J で確定できるのは精算済みが 1 名以上の場合。2名受付時は通常に固定。共通確定では未精算/未終了カードを次シーンに連れない。2P のみ条件を満たせば選択アカウントと側を 1P に繰り上げる。精算後にスコアの非同期再読込を待ち、入場・選択音声停止、ドンと歓声、キャラ導入を開始。1P なら決定時 F1 押下中はバトンタッチ、F2 押下中は特訓に上書き（同時は F2 が後）。段位フォルダーがなければ通常。確定後 1600〜2060ms に黒を 0→255、タイトル BGM 音量を 210→0、2060 で停止して通常選曲／段位選択に切替。Q はカードなしで精算済みの1人目を立て現在モードへ直行、T はカードと太鼓アニメを完了値へ進めモード選択まで、いずれも設定が開いていないときのショートカット。

根拠：`G/src/Scenes/Title/Title.cs` 189–411、414–455、717–1030、1257–1368。決済の状態と演奏プロフィールを別概念にする。

## SCENE-A02 デモ紹介のテンプレート・差し替え・音量

デモは `Texture/Demo/Animes` 優先、旧 `Texture/00.Demo/Animes` を代替とし、番号ディレクトリの `Anime.aup2` を昇順で循環。初回描画でロードを開始。映像の入り・終わりのフェードフレーム数は `min(30,max(1,floor(全フレーム数/3)))`。タイトルへ切り替えるとき描画中アニメを止め、絵は同じまま 500ms で黒へ、黒いフレームを描いたのち、タイトルのフェードインを 500ms 開始する。素材が読めない場合、再生可能な次候補を試し、全て失敗でタイトルへ。

紹介曲ファイル `Info/TaikoDiveLauncher/demo-songs.json` のサイズは 1 MiB 以下、`enabled` が真、v1 `songs` または v2 `entries`。1〜13件、要素/付属リスト null や手動リスト 5 曲以上は設定全体を不使用。各主曲が無効ならその枠だけ除く。自動候補は Songs の `.tja` ファイルを一度列挙し、再帰でリンク・アクセス不可を飛ばし、枠ごとにシャッフル。主曲を除く有効曲を先頭から最大 4 件。1〜3 件は順番に循環補完、ゼロなら主曲を使う。手動は位置順を変えず、足りない位置だけ同じ位置の自動候補で補完。確定した有効枠を `テンプレート枠 index mod 有効枠数` で使用する。相対 `.tja` と `WAVE` は正規化後も Songs 内で、配下のリンクを許さない。ヘッダは先頭 `#START` まで、UTF-8 strict→CP932、キー大小同一、同キー後勝ち。最大 8 MiB、曲名空ならファイル名、`TITLE`/`SUBTITLE`/`GENRE` は 200 UTF-16 単位まで、副題先頭 `--`/`++` をたたむ。ジャンル未指定は上位 `box.def` の `GENRE` の近いもの。曲音量 0〜200（既定100）、`DEMOSTART` は有限非負の秒・最大86400（不成立は0）。

テンプレートで `Song_Main_i.png` の最小開始を表示境界、`Songi.ogg` の開始/終端を音声境界として読む。表示開始は昇順厳密。音声は両端含む。表示は現フレーム以下で最新の境界。小ジャンル/パネルの行は対応素材レイヤー番号の昇順先頭4行、メイン・サブ音楽名は素材名に埋めた番号で割当。PNG のシート形式と生成の詳細は媒体章。A の `Texture/Demo/Animes/2/Anime.aup2`（1920×1080、60fps）から得たフレーム番号は以下。表示と音声の境界は同一に丸めない。

各音声枠で主曲一つだけロード、前の音を停止・破棄。`DEMOSTART×1000` を切捨てて開始位置とし、取得できた音声長を越える場合は 0。フレーム当たり `1000/max(1,fps)` ms、予定継続長 L は「終端−開始」フレーム分と音声残長の小さい方（長さ不明なら前者）。開始位置に枠に入ってからの経過 e の整数部を足す。音量係数は L が正なら `clamp(min(e,L-e)/min(500,L/2),0,1)`、非正なら 0。`255×SONGVOL/100` の整数部に乗じ最近接偶数丸め、再生前に音量設定。デモを退出する時はその音量をさらに `1−退出進捗` 倍。音源ロードが失敗した枠は無音。設定やテンプレートに問題があり置換構成が作れなければ、標準の紹介アニメと同梱音声を選ぶ。根拠：`G/src/Common/Song/DemoSongPlaylist.cs`、`DemoSongTemplate.cs`、`DemoSongPreviewFade.cs`、`G/src/Scenes/Demo/DemoSongShowcase.cs`。

## SCENE-A03 難易度・オプション

初期は実難易度 3（鬼）優先、なければ 4（裏の絵を表 5 の枠に表示）、なければ実難易度 2→1→0 の最初の存在点。表の候補の index は 0=戻る、1=オプション、2〜5 が実難易度0〜3相当。プレイヤーごとにコースや裏選択を保持し、元譜面にないコースを飛ばす。Tab で裏を切り替えられるのは鬼枠にいて対向のコースが存在するとき。通常・1人・演奏難易度で F11 がリプレイ要求の循環、成功でドン、不可でカッ、当該フレームの他の処理を打ち切る。F6 は通常→バトンタッチ→特訓→通常（実装の else は他モードからも通常に戻す）。通常でなくなるとリプレイ要求を消す。曲・副題の中心 X=960、Y=143 / 219。

| 行 | 値 | 初期値 | 図柄 index 最小..最大 |
|---:|---|---|---|
| 0 | ばいそく：1.0〜2.0 は 0.1 刻み、2.5 / 3.0 / 3.5 / 4.0 | 1.0 | 0..14 |
| 1 | ドロン 切/入 | 切 | 15..16 |
| 2 | あべこべ 切/入 | 切 | 15..16 |
| 3 | ランダム なし/きまぐれ/でたらめ | なし | 19..21 |
| 4 | 演奏スキップ 切/入 | 切 | 15..16 |
| 5 | ノーツ位置（index×10） | 0 | 0..5 |
| 6 | どんちゃんの声 切/入 | 入 | 15..16 |
| 7 | 太鼓音色（選択番号、SoundLoad の定義順） | 0 | 0..9 |

開いた直後は入力を 1 フレーム無視。P1 の左右は D/K、決定は F/G/H/J、2P 左右 Z/V、決定 X/C。順序は左→右→決定で、端で循環せずそのフレームを打ち切る。決定で次行、最後で閉じて選択を演奏オプションへ適用。各変更でアイコンを更新。パネルの開閉は 400ms。根拠：`G/src/Scenes/CourseSelect/CourseSelect.cs` 649–682、893–1067、1069–1106、1644–1681、`G/src/Scenes/SelectSong/OptionConfig.cs`。

## SCENE-A04 F4 設定の境界

タイトル・通常選曲・段位選択で開閉し非対象シーンに入ると閉じる。曲検索中やキー入力取得中は F4 を一般の閉じるキーとして使わない。Tab / Shift+Tab は次/前のタブ、↑↓で行循環、PageUp/Down は表示行数ぶん端で制限、左右で値変更、Enter 決定、Esc で戻る。ドロップダウン中は ↑↓・Enter と Esc/右クリックを優先、マウスで行/値を選択可。項目は次の順。

| 区分 | 項目順 |
|---|---|
| 画面 | 画面サイズ、ボーダーレス、フルスクリーン、垂直同期、フレームレート上限、背景ムービー表示、タイトル表示 |
| サウンド | マスター・曲・効果音（各 0〜100、左右は5刻み）、出力方式、バッファサイズ |
| キーコンフィグ | 各太鼓の入力行。通常の新規入力で変更、Shift を保持して追加入力、取得中 Delete で消去 |
| 演奏 | 自己ベストリプレイを保存、詳細リザルト、ゲストモード、フリープレイ |
| システム | テクスチャ16bit、背景16bit、曲の音声の圧縮保持、メモリ使用量を記録 |
| ルートの操作 | 楽曲データを再読み込み、変更を反映して再起動 |

入力等の確定時にその場で保存し通知する。音量等は更新時のアダプターへ、出力方式・バッファ等は次回サウンド初期化で反映。根拠：`G/src/Scenes/Settings/SettingsMenuDefinition.cs`、`G/src/Scenes/Settings/SettingsOverlay.cs` 27–342、794–848、985–1087。

## SCENE-A05 選曲の試聴・検索と2P確定

- 試聴のスクロール中の要求は最後の要求から 300ms 待ち、確定時に直前候補を破棄して中央の `WAVE` と `DEMOSTART×1000` を渡す。即時経路も旧音を止めてから新音を準備。対応するプレビュー音は 50ms 入り／150ms 終わり。要求を連打しても破棄待ちを音源ハンドルの早期解放と取り違えない。`G/src/Scenes/SelectSong/SelectSong.Preview.cs`、`PreviewSong.cs`、`SelectSong.Recovery.cs` 63行。
- 2P は Z/V で左右、X/C で確定。難易度の存在条件を各側で評価、鬼の端からさらに右を押し10回で裏表を入れ替える。切替時の現在の裏表表示を両側に伝えるが、既に確定したプレイヤーの最終裏表フラグは押下時に別保存。戻るの決定で難易度選択を閉じる。片方確定だけでは開始しない。2P モードで両方確定、1P モードで P1 確定で曲ロード開始。確定済み側の左右操作で確定解除はしない。`G/src/Scenes/CourseSelect/CourseSelect.cs` 1119–1292。
- F3 検索は入力欄の最大64、文字入力は IME 対応。検索条件・ジャンルのいずれも空なら曲を出さない。条件変化で全結果を再列挙、インデックス0とスクロール0へ戻す。文字入力欄の Enter は一覧にフォーカスを移すだけ（同 Enter を曲決定に二重消費しない）。入力欄の Esc は閉じる、一覧の Esc は入力欄へ戻る。↑/↓で行、PageUp/Down でページ、ホイールでスクロール、Enter/左クリックで曲へ飛ぶ。曲の再発見が成功したときだけ閉じる。F3 は開閉、別シーンへ出たら即時閉じる。`G/src/Scenes/SelectSong/SongSearchOverlay.cs` 220–380、471–530、856–1018。
- 検索パネルは 1920 座標で幅1066×高さ944、X427/Y0。入力欄 X455/Y34/幅984/高さ74。結果行左 X455、上 Y196、列ピッチ140、行高さ132、幅984、5行表示。開く380ms、閉じる320ms（閉方向は進捗の三乗）、検索欄/一覧のフォーカス状態を色で区別。曲名の表示幅590、長い曲名は開始1200ms待機の後70px/sで動く。ジャンルの行は5列。`G/src/Scenes/SelectSong/SongSearchOverlay.cs` 74–176、410–444、1068以降。
