# 04c 曲カタログと検索・BOXの実装契約

対象はゲーム本体の固定スナップショット G。以下はソース上の挙動を記述し、未確認事項は明示する。

## 列挙・BOX

- G `src/Scenes/Loading/LoadSongs.cs:24-91,217-289,365-407`：実行ファイル基底直下の *.def と、直下ディレクトリ以下の再帰 *.def を列挙。直下 Texture/Sound/Libraries/Info/Log/Screenshot は ordinal 大文字小文字無視で除外。Songs や box.def に限定しない。列挙順をジャンル順とし、複数 def の重複も除去しない。OS列挙順は保証されない。
- def 親配下の *.tja と *.dan を両方再帰列挙。GENRE が厳密に 段位道場 なら dan のみ、その他は tja のみ。通常曲は並列解析後、列挙順に戻す。曲 GENRE が空なら親 GENRE を補完。ゲスト以外は現ユーザーのスコアを読む。拡張子の大文字小文字は実行環境の列挙規則に依存。
- def は Shift_JIS/CP932 の StreamReader（BOM検出あり）。#TITLE、#GENRE、#FORECOLOR、#BACKCOLOR のみ大文字小文字を区別して読み、コロン分割の第2要素を trim。認識キーのコロン欠落・不正色は InvalidDataException として def 単位で警告しスキップ。列挙・アクセス等の他例外は一般に握りつぶさない。段位の InvalidDataException は dan 単位で警告・破棄し継続。通常 tja はこのループで個別救済しない。
- 通常曲は追加前に現在のバー数が正で7の倍数なら BACKBOX を挿入し、最後にも必ず追加。判定は曲数ではなく閉じるバーを含むリスト数。番号はバー位置+1。段位は途中に挟まず末尾に追加。
- 段位順は五級、四級、三級、二級、一級、初段、二段、三段、四段、五段、六段、七段、八段、九段、十段、玄人、名人、超人、達人、外伝、創作、未知。同順位は発見順。段位譜面の親配下に tja がある場合、仮想「段位道場の課題曲」BOXを追加。親ディレクトリと tja パスを ordinal ignore-case 重複排除、パスを同比較でソートし、各曲 GENRE を仮想名に上書き、段位BOX画像を共有。実ファイルは作成しない。

## 曲順と外部 Songs

- G LoadSongs.cs:320-363：ジャンル直下 .taikodive-order は UTF-8 のジャンル相対パスを1行ずつ。trim、逆斜線を / に変換、空行無視、ordinal ignore-case で最初の重複だけ採用。登録曲をファイル内順に先頭へ、未登録は元列挙順で後ろへ。不存在の登録行は無視。G は読取の IOException/UnauthorizedAccessException をログし元順で継続。段位順には適用しない。

外部 Songs の設定・復元や曲順を書き出す手順は [Launcher の曲データ編集](../launcher/04-data-editor.md)。配置済みの Songs を列挙する本体側の規則は同じ。

## 検索

G src/Scenes/SelectSong/SongSearchIndex.cs:97-181、SongSearchQuery.cs:25-295：BaseGenre を順に走査し SCORE のみを索引化、最近遊んだ曲 BOX は重複回避のため除外する。他 BOX や仮想段位課題曲による重複は排除しない。索引は遅延構築・曲再読込時に無効化。タイトルとサブタイトルを改行で連結して検索し、ジャンルは曲自身ではなく所属 BOX の GENRE を使用。難易度・王冠はキャッシュせず参照元から都度取得する。

正規化は全角 ASCII 記号・英数字 U+FF01〜FF5E を半角、全角空白を半角、カタカナ ァ〜ヶ をひらがなへ、ASCII A〜Z を小文字へ変換。それ以外はそのまま。Unicode NFKC ではなく、半角カナや濁点合成、一般 Unicode の大文字小文字の同一視はしない。タイトル/副題と入力に同じ正規化を施し ordinal 部分一致。入力は半角空白・タブで分割し全条件 AND、空検索は結果なし。引用符や OR の構文はない。

- コースキー: easy/かんたん/簡単/梅、normal/ふつう/普通/竹、hard/むずかしい/むずい/松、oni/おに/鬼、ura/edit/うら/裏。共通レベルキー level/lv/star/れべる/星。比較は =、==、!=、>、>=、<、<=。値は整数から ★ と ☆ を全除去して解析、範囲制限なし。
- クリアキー clear/crown/くりあ/王冠。値は 0 noclear/未くりあ/なし、1 clear/くりあ、2 fc/fullcombo/ふるこんぼ、3 dfc/donda/どんだふるこんぼ/全良/ぜんりょう、または整数。王冠の内部値に1を加える。未存在譜面は比較しない。
- genre/じゃんる は =、==、!= のみで BOX ジャンルの正規化済み部分文字列を包含・除外。他の演算子、未知キー、値欠落、整数不正、単独 ! はエラーではなくトークン全体を曲名語として扱う。
- コース未指定の各条件は「存在する5コースのいずれか」で個別に評価し、複数条件は異なるコースで満たしてもよい。レベル条件がすべて同一の明示コースなら全 clear 条件をそのコースに束縛する。異なるコースまたは共通レベルが混ざれば束縛しない。

## 最近遊んだ曲

G src/Common/Song/RecentSongs.cs:18-245、Scenes/Result/Result.cs:181：GENRE が厳密に「最近遊んだ曲」の既存 BOX を開く直前に内容を再生成する。BOX 自体は自動作成しない。ユーザー別 Info/ScoreData/<ユーザー>/Recent.json の Songs 配列に実行基底相対パスを新しい順で最大30件保持。同一パスは ordinal ignore-case で既存を除いて先頭に移す。ゲスト・空パスは保存しない。読込・保存例外はログし、読込失敗は空。キャッシュはユーザー名 ordinal 一致時に再利用する。

他の BOX の SCORE を相対パスで探索し、大文字小文字無視で同一なら最初の曲を使用。消去・移動された曲は表示からスキップし履歴自体はその場で削除しない。表示用バーはヘッダを複製し、譜面・スコアは共有する。閉じるバーは上記と同じバー数規則、空でも末尾に必ず置く。検索索引にはこの BOX を入れない。

## デモ曲との境界

G src/Common/Song/DemoSongPlaylist.cs、Scenes/Demo/Demo.cs、Scenes/SelectSong/SelectSong.Preview.cs：デモ紹介は Info/TaikoDiveLauncher/demo-songs.json を別途読み、譜面を参照する独立した仕組みであり、選択や再生でカタログや履歴に自動追加されるものではない。選曲プレビューは選択譜面のディレクトリと WAVE を結合し DEMOSTART 秒をミリ秒に変換して再生する。紹介側も譜面の DEMOSTART を使うが設定・検証処理は別物。

## 受入テスト例

1. 除外ディレクトリの def は無視、別ディレクトリの任意名 def は検出。親子 def は同一 tja をそれぞれ含み得る。不正色 def は飛ばし次の def を処理、アクセス拒否等は必ずしも継続しない。
2. 空 BOX は BACKBOX だけ。8曲なら 7 SCORE、BACKBOX、1 SCORE、末尾 BACKBOX。さらに追加する場合の挿入位置をバー数で検証する。
3. 保存順が B、b、欠損、A で列挙が A、C、B なら B、A、C。未登録曲間の元順を保持。順序ファイル読取拒否時 G は元順。L は曲が追加・削除された古い一覧の保存を拒否する。
4. ｃａｎｄｙ と CANDY、キャリー と きゃりー は一致。半角ｶﾅを全角かなへ変換しない。空検索は0件。未知の foo=1 は文字列検索となる。
5. oni>=9 clear=fc は同一おに譜面のレベルと王冠を要求。level>=9 clear=fc は別コースでも成立。存在しない譜面は != でも一致しない。genre!=アニメ は BOX ジャンルの部分一致を除外。
6. 履歴へ A、B、a の順で追加すれば a、B。31件で末尾を切る。消えた譜面は表示から除外、最近 BOX 自体の検索重複はない。ゲストは履歴を保存しない。

上記はソース読解に基づく受入ケースであり、この文書作成時に実行したテスト結果ではない。
