# TaikoDive 本体＋Assets の再実装仕様

ゲーム本体は G、配布素材は A を独立した参照版として固定する。実行時の素材は本体と組で使うが、本体・Assets のコミットと配布版を同一としない。主要な基準は G `fb12417`、A `7c5bb71`。背景の追補は第06c章、開発版は第09章に分ける。版の全識別子は [全体像](00-architecture.md)。

## 素材について

素材のファイル名・配置・ハッシュ・描画の規則はこの資料にある。実画像・音・フォント・GLB は別途必要であり、目録だけでは元の画素や音を再生できない。
