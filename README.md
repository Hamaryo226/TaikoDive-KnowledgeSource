# TaikoDive 独立再実装仕様書

**対象：ゲーム本体・ランチャー・配布素材。** **追補版 r3** は r2 の固定仕様を維持し、現行構成と移植案の比較を追加した版。本編の基準はゲーム `fb12417`、ランチャー `a1267f0`、素材 `7c5bb71` のまま。2026年11月27日（JST）の再照合で追加されていた学マス専用背景は、ゲーム `c9ffa41`・素材 `9e16eca8` の差分として分離した。開発版は `dev` の補遺。全文書は日本語の Markdown と UTF-8 の表。プログラム本体、実行ファイル、画像、楽曲、保存データは含まない。

## r3 の追加：現行の課題と改善分析

[27 現行構成の制約と移植案](27-architecture-tradeoffs.md) は別基準の main を照合した分析。メモリの重複、判定・描画・時計の結合、他言語・ライブラリの比較、採用試験を含む。ゲーム G3／素材 A3 の学マス PNG 化は第27章に明記し、r2 の G2/A2 の動画仕様を上書きしない。提案は未実装。

最初に仕様 00 を読み、03 と 04 の互換データを実装し、02 を外部時計で試験できる形で作る。次に 01、05、06、07 をつなぎ、最後に 08 で元の Windows 版と照合する。基準バージョンの関数名・ファイル名は確認のための出典であり、その言語や UI 基盤を再使用する必要はない。原文に概略と詳細が併記される場合は、a/b/c の明示的な補足を該当箇所に適用する。

**合格範囲を混同しない。** 譜面解析・判定・保存互換と画面・音の再現性は別の合否。素材そのものを文章から復元するのは対象外であり、元の見た目・音には対応する素材とフォントが必要。仕様の欠落または実測未確認の範囲は 14 と各章末に明記した。全機能の同等動作や OS をまたぐピクセル・音声・入力遅延の一致を認証した文書ではない。
