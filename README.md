# TaikoDive 独立再実装仕様書

このリポジトリには、別ソフトである **TaikoDive 本体＋Assets** と **TaikoDive Launcher** の仕様を分けて収録する。再実装する対象の入口から読む。

| 対象 | 入口 | 範囲 |
|---|---|---|
| **本体＋Assets** | [game/README.md](game/README.md) | 画面遷移、演奏・判定、譜面・保存、描画・音声、素材の形式と配置、本体の検証・移植分析 |
| **Launcher** | [launcher/README.md](launcher/README.md) | 起動・画面、設定・曲・プロフィール・履歴の管理、更新と修復、Launcher の検証・移植分析 |

[連携契約](INTEROP.md) は起動引数・共有ファイル・パッケージなど、**二つの間の接点だけ**を扱う。ゲーム本体は対応する Assets を配置すれば Launcher なしで直接起動できる。本体と Assets の版は個別に固定し、Launcher の版とは混同しない。

文書と表のみを収録。元コード、実行ファイル、画像・楽曲・フォント・モデル、ユーザーの保存データは含まない。論理・データの互換、画面・音の実機一致は別々に判定する。
