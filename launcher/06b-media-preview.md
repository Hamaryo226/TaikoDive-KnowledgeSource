# 06b｜Launcher の AUP2 プレビュー

Launcher のプレビュー用ローダーは [本体の AUP2 ローダー](../game/06b-media-details.md) と別実装。ここでは Launcher 内で描く画像だけを扱う。本体に委任する3Dの呼出し側は [画面・保存](20-ui-persistence-details.md)、本体側のCLIは [連携契約](../INTEROP.md)。

## Launcher の AUP2 はゲーム版と別実装

根拠: `launcher/Services/Aup2Animation.cs`。ゲーム版との差を再現する。
- 画像、標準描画、拡大率エフェクトだけを解析し、動画・音声・グループ・反転は扱わない。`scene.` の判定は大文字小文字を区別せず、全シーンの値が後勝ち。幅400、高さ100、fps60で開始し、数値変換に失敗するとその値は0になる。結果の幅・高さは最低1、fpsが正でなければ60。
- `frame` は先頭2項のみを開始・終了とし、変換失敗項は0。中間点を使わない。存在する画像のみ残し、layer昇順の安定順。全長は画像を含まないものも含め全オブジェクトの終了＋1の最大値、最低1。画像が1件もなければ null、ファイル不在も null。読み取り例外の捕捉はこのメソッド内にはない。
- 画像は記録文字列のバックスラッシュをスラッシュに直し、末尾名を AUP2 と同じフォルダに結合するだけ。ゲーム版の二重拡張子救済・親サブフォルダ探索はない。
- 値は `|` より前の先頭連続数値を読み、方式は元の文字列中に瞬間移動があれば優先、次に加減速、他は直線。時間制御点は無視し、複数値は時間を均等分割する。瞬間移動では進行度1でも最後の区間の左値になる（ゲーム版は最後の値）。
- BGRA 変換では各色を `(色×元α＋127)/255` にする。黒背景除去指定時のみ出力αは `(max(R,G,B)×元α＋127)/255`、そうでなければ元α。バイト数が4の倍数でなければ例外。
